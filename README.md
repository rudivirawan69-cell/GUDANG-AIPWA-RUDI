description: Operasi gudang GudangAI berbasis Google Sheets/Apps Script, termasuk ekstraksi PDF order, pemetaan nama-ke-kode CV/PT, transaksi aman, Shortage HOLD, PO CS 43 item, deduplikasi, audit, dan PWA/outbox offline. Gunakan saat memproses order PDF, menulis atau memvalidasi transaksi stok, membuat PO, mendiagnosis duplikasi, atau menguji sinkronisasi dashboard.GudangAI Warehouse OperationsGunakan skill ini sebagai prosedur ketat untuk CV dan PT. Perlakukan Google Sheets sebagai sumber kebenaran untuk master, stok, histori, dan hasil PO. Jangan mengarang nama barang, kode, qty, rating, testimonial, atau hasil transaksi.Aturan keselamatan mutlak1.Pisahkan entitas. Tentukan CV atau PT dari instruksi dan kode. Jangan memakai master CV untuk PT atau sebaliknya.2.Hormati protected range. Payload tulis hanya boleh membawa tanggal, kodeBarang, qty, dan keterangan. Jangan mengirim atau menulis namaBarang, nama, atau satuan; kolom itu dibaca dari Sheet/master.3.Validasi sebelum write. Jalankan read-only status, master lookup, dan bila tersedia validateTransaction. Jangan menulis jika kode ambigu, entitas tidak konsisten, periode salah, atau respons server timeout.4.Jangan retry write yang ambigu. Jika request timeout setelah kemungkinan write, lakukan read-back berdasarkan transactionId/clientNonce sebelum mengulang. Satu request harus memiliki idempotency key unik.5.Terapkan Shortage HOLD. Untuk barang keluar dengan stok tidak cukup, tulis qty: 0; masukkan order qty, stok tersedia, kekurangan, dan tindak lanjut manual di keterangan. Jangan membuat stok negatif.6.Fail-closed offline. Offline hanya boleh membaca snapshot dan menyimpan draft REVIEW. Jangan auto-sync transaksi stok, PDF, atau PO dari outbox.
